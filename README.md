# Enkidu modules and artwork

Saved Enkidu and Anzu Blender artwork and Unity project, synchronized on 2026-11-11.

- `Blender/`: Enkidu and Anzu character models, materials, rigs, walk/run/jump and mounted-walk animation, renders, exports, and supporting scripts.
- `Blender/enkidu-action/Enkidu_walk_run_jump_v15.blend`: latest saved action sequence.
- `Blender/Anzu/`: Anzu creature scenes, wing and walking animation, rendered frames, and previews.
- `Blender/Mounted Walk/`: Enkidu riding Anzu models, motion checks, scripts, and preview renders.
- `Concept-Art/Anzu/`: current Anzu and mounted-Enkidu visual studies.
- `Unity/Enkidu/`: Unity Assets (including metadata), Packages, ProjectSettings, drafts, and project notes. Open this folder with Unity Hub; the editor version is recorded in `ProjectSettings/ProjectVersion.txt`.
- `Unity/Update-Packages/`: packaged Unity updates for the running Enkidu and Anzu desert scenes.
- `upload-manifest.json`: file sizes and SHA-256 checksums for the uploaded source snapshot.

Install Git LFS before cloning to retrieve large binary assets. If the repository is already cloned, run `git lfs pull`.

Unity caches, logs, user settings, and automatic Blender backup files are excluded. Original local project files are preserved. Unsaved editor changes are not part of this snapshot.
